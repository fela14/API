Flask Blog Application 📝💻

A simple blog web application built with Flask, following Corey Schafer’s tutorial series. Users can read 📖, create ✍️, edit ✏️, and delete 🗑️ blog posts, with a clean and minimal interface.

🔗 Live Demo: ...

Features ✨🚀

User registration and login system 🔐

Create, edit, and delete blog posts ✍️🗑️

Password hashing for secure authentication 🔑

Flash messages for user feedback 💬

SQLAlchemy ORM with SQLite database 🗄️ (can be switched to MySQL/PostgreSQL)

Bootstrap-powered responsive design 📱💻

Tech Stack 🛠⚡

Python & Flask 🐍

Flask-Login for authentication 🔒

Flask-WTF for forms 📝

Flask-SQLAlchemy for ORM 🗃️

Bootstrap 5 for styling 🎨
